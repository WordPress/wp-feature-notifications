## Description

### What
Adds the `PUT /wp-notifications/v1/notifications/{id}` endpoint and repository support to update per-user notification state.

### How
Registered the item route in `Notification_Controller` with an authentication check, UTC date normalization, and error handling for invalid or empty payloads. Extended `Notification_Repository` and `Wpdb_Notification_Repository` with `update_state()`, scoping queue table updates to both `message_id` and the current `user_id`. Added PHPUnit test coverage for route handling and auth.
