## Description

Part of #302. Depends on #42. Blocks #307, #176 and #303.

### What problem does this address?

`Wpdb_Notification_Repository` is never instantiated anywhere, so the controllers have nothing to query even once the repository is implemented.

### What is your proposed solution?

Add a filtered accessor in `includes/load.php`:

```php
$repository = apply_filters( 'wp_notifications_repository', new Persistence\Wpdb_Notification_Repository( $wpdb ) );
```

Inject it into controller constructors as a **required** argument, so a controller can't be constructed unwired and tests can inject a fake. `notify()` (#303) uses the same instance.
